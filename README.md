# Клиентский Радар

Живая витрина данных NCA-RS (VK Mini App, [app54674554](https://vk.com/app54674554)) — статистика по собранным сообществам, постам и профилям пользователей в четырёх предметных областях исследования.

## Статус

MVP: статичная страница со снимком данных, задеплоенная на `vk.markly.ru`. Следующий шаг — подключение живых данных и проверка VK Bridge launch params через `VK_SECURE_KEY`.

## Деплой

`.github/workflows/deploy.yml` синхронизирует `index.html` на сервер по SSH при каждом push в `main` (используется отдельный непривилегированный пользователь `radar`, ограниченный каталогом `/opt/customer-radar`).

Секреты репозитория:

- `SSH_HOST`, `SSH_USER`, `SSH_PRIVATE_KEY` — уже настроены.
- `VK_SECURE_KEY` — защищённый ключ приложения из VK Developers (Настройки → Ключи доступа). Добавьте его в Settings → Secrets and variables → Actions — деплой сам положит его в `/opt/customer-radar/.env` на сервере.
