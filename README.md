# НейроКонт: ИИ-радар конкурентов (Модуль 1 / Проект Маркли)

**VK Mini App #54674554** (`https://vk.com/app54674554` · `https://vk.markly.ru`)

Интеллектуальный сервис бизнес-аналитики и поиска прямых конкурентов во ВКонтакте для предпринимателей, маркетологов и таргетологов. Сервис автоматически определяет нишу по ссылке или названию сообщества, формирует семантический профиль, выполняет гибридную классификацию кандидатов с отсевом информационного шума и предоставляет интерактивный механизм Active Learning для дообучения классификатора на лету.

---

## 🚀 Ключевые возможности

1. **Быстрый старт и демо-пресеты:**
   - Анализ по ссылке на любое открытое сообщество или короткому имени (`https://vk.com/dodo`, `dodo`, `club12345`).
   - 3 готовых демо-пресета в 1 клик для мгновенного знакомства и прохождения модерации:
     - 🍕 **Доставка еды** (`dodo`)
     - 🏋️ **Фитнес-клуб** (`alexfitness`)
     - 🔧 **Автосервис** (`fitauto`)

2. **Автоматическое распознавание ниши (Cold-Start NLP):**
   - Экстракция предметной области из названия, описания, статуса и категории сообщества без использования дорогостоящих внешних LLM.
   - Определение географической привязки (крупнейшие города РФ).
   - Извлечение 5–8 релевантных поисковых ключевых запросов (униграммы и биграммы) с помощью TF-IDF.
   - Возможность ручной корректировки предметной области и интерактивное добавление/удаление тегов запросов (ChipsInput).

3. **Легковесный нейросетевой ML-пайплайн на CPU (< 30 мс):**
   - Символьная векторизация `TfidfVectorizer(analyzer='char_wb', ngram_range=(3, 5))` для надёжного учета корней русских слов и окончаний.
   - Сжатие в латентное пространство признаков $\mathbf{h}_i \in \mathbb{R}^{24}$ через `TruncatedSVD` (аналог скрытых состояний LSTM).
   - Скоринг коммерческих маркеров (+бонус за слова «доставка», «меню», «цена», «прайс», «абонемент», «ремонт» и др.).
   - Лексический фильтр отсева информационного шума (-штраф за «подслушано», «барахолка», «отдам даром», «мемы», «дтп»).
   - Калибровка вероятности релевантности $P_{rel} \in [0.02; 0.99]$.

4. **Мгновенное дообучение на лету (Active Learning):**
   - Выделение пограничных сообществ с высокой неопределенностью ($P_{rel} \in [0.40; 0.65]$).
   - Интерактивный блок разметки («👍 Конкурент» / «👎 Шум»).
   - Дообучение `LogisticRegression` на признаках $[\mathbf{h}_i, P_{base}]$ за 5–15 мс и автоматический пересчет всей выдачи.

5. **Дашборд и клиентская фильтрация:**
   - Сводный баннер: проверено кандидатов, отобрано ИИ, отсеяно шума.
   - 4 мгновенных клиентских фильтра:
     - Размер аудитории: Все, До 5 тыс., 5–50 тыс., 50–200 тыс., 200 тыс.+
     - Порог уверенности ИИ: Все релевантные ($\ge 50\%$), Только прямые ($\ge 85\%$), Показать все (включая шум)
     - География: Все города / Только локальный город
     - Открытость: Только открытые сообщества
   - Сортировка по скору ИИ или аудитории.

6. **Законченные бизнес-инструменты экспорта:**
   - **Экспорт ID для таргета ВК:** копирование списка ID отобранных групп в буфер обмена (`VKWebAppCopyText`) для загрузки в рекламный кабинет ВКонтакте.
   - **Скачивание CSV:** формирование структурированного файла `competitors_export.csv` с метаданными и скором ИИ.
   - **Сохранение подборок:** запись отчетов в `VKWebAppStorage` и `localStorage` для быстрого доступа во вкладке «Мои подборки».
   - **Поделиться:** отправка ссылки на сервис через `VKWebAppShare`.

## 🛠 Архитектура и стек технологий

| Компонент | Стек / Технология | Особенности реализации |
| :--- | :--- | :--- |
| **Frontend** | Vanilla JS + CSS3 + VKUI Design System | Zero-build в едином `index.html`, работа без Node.js, поддержка светлой/темной темы (`VKWebAppUpdateConfig`), History API для кнопки «Назад» на Android. |
| **Backend** | FastAPI + Uvicorn + Pydantic v2 | Асинхронный сервер, потребление RAM ~60 МБ, эндпоинты `/api/v1/detect-niche`, `/api/v1/classify-groups` и легаси `/api/subjects`, `/api/cities`, `/api/stats`. |
| **ML-ядро** | Scikit-learn + NumPy | TF-IDF (char 3-5 n-grams) + TruncatedSVD + лексические словари + LogisticRegression с sample_weight для Active Learning. Работает за 15–30 мс на 1 vCPU без GPU. |
| **Хранилище данных** | SQLite (`api/cache.db`) | Демо-пресеты и кэш поисковой выдачи `vk_search_cache` (TTL 7 дней). Сервис мгновенно отвечает даже без внешних токенов. |
| **Безопасность** | HMAC-SHA256 (`verify_vk_sign`) | Проверка подписи параметров запуска `X-VK-Launch-Params`, заголовки безопасности nosniff, frame-ancestors для `vk.com` и `vk-apps.com`. |

## 🚦 Запуск и тестирование локально

```bash
# 1. Создание виртуального окружения и установка зависимостей
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. Инициализация демо-пресетов в SQLite
python3 api/refresh_cache.py

# 3. Запуск FastAPI сервера
uvicorn api.main:app --host 127.0.0.1 --port 8000 --reload
```

## 🔄 CI/CD деплой

При каждом пуше в ветку `main` GitHub Actions запускает пайплайн `.github/workflows/deploy.yml`:
1. Валидация HTML-файлов (`html.parser`).
2. Валидация синтаксиса Python (`ast.parse`).
3. Доставка статики и API-кода через SSH/rsync на VPS-сервер.
4. Безопасный перезапуск системной службы `customer-radar-api.service`.
