# Проект Маркли (Customer Radar)

Сервис аналитики целевой аудитории и активных сообществ во ВКонтакте для бизнеса ([VK Mini App #54674554](https://vk.com/app54674554)). Позволяет исследовать структуру рынка, метрики вовлечённости и публикации с наибольшим откликом по отраслям и городам.

## Возможности сервиса

- **Аналитика по ключевым направлениям бизнеса:** B2B-маркетинг и привлечение клиентов, сопровождение тендеров и госзакупок, службы доставки и локальный бизнес;
- **Географическая сегментация:** общероссийские агрегаты и выборка по отдельным городам;
- **Метрики вовлечённости:** число сообществ, публикаций, суммарный отклик, отметки «Нравится», репосты, комментарии;
- **Контентные бенчмарки:** топ публикаций с максимальной вовлечённостью в каждой нише;
- **Автоматические рекомендации:** расчёт частоты публикаций, плотности аудитории и вирального потенциала;
- **Персональные инструменты:** сохранение отчётов в локальное хранилище устройства, копирование резюме и публикация ссылки через VK Bridge.

## Архитектура и технологии

- **Клиент (`index.html`):** современный интерфейс в дизайн-системе VKUI с поддержкой светлой и тёмной темы (`VKWebAppUpdateConfig`), профилем пользователя (`VKWebAppGetUserInfo`), навигацией через History API (с поддержкой аппаратной кнопки «Назад» на Android) и локальным роутером состояний (`home`, `onboarding`, `results`, `saved`, `support`, `privacy`, `terms`);
- **Правовые документы (`privacy.html`, `terms.html`):** разработаны в соответствии с требованиями модерации VK Mini Apps (оператор: ООО «Визуальный навигатор»);
- **API (`api/main.py`):** легковесный сервис на FastAPI:
  - Автономная работа с локальным хранилищем данных `cache.db`;
  - Серверная проверка подписи параметров запуска VK (`sign`) по стандарту HMAC-SHA256 (`VK_SECRET_KEY`);
  - Эндпоинты `/api/subjects`, `/api/cities`, `/api/stats`;
- **Конфигурация Nginx (`nginx.vk.markly.ru.conf`):** раздача статических файлов по HTTPS, защита служебных файлов (`.env`, `.sqlite`, `.db`) и проксирование API на `127.0.0.1:8000` с передачей заголовка `X-VK-Launch-Params`.

## Деплой

CI/CD реализован через `.github/workflows/deploy.yml` при каждом push в ветку `main`:
1. Валидация разметки HTML (`index.html`, `privacy.html`, `terms.html`);
2. Валидация синтаксиса Python (`api/main.py`, `api/refresh_cache.py`);
3. Синхронизация статических файлов в `/opt/customer-radar/public/`;
4. Синхронизация кода API в `/opt/customer-radar/api/`;
5. Безопасный перезапуск исключительно сервиса API (`sudo -n systemctl restart customer-radar-api.service`), не затрагивая сторонние службы;
6. Запись защищённого ключа приложения `VK_SECRET_KEY` в конфигурацию сервера.
